## Design Context

### Users
Kids 8 and up, often playing with a sibling, friend, or parent nearby. They arrive at the setup screen excited to play — not to configure. Setup is a brief ritual before the real fun, so the UI must be fast, legible, and reward curiosity without demanding it. Adults may also interact (choosing settings), so nothing should be condescending or oversimplified.

### Brand Personality
Whimsical, clever, warm. The game is called "Mathemagic" — math is the magic, not the theme. The tone is a library that knows a few spells: bookish and a bit enchanted, never sterile, never infantile. Think: a friendly wizard's study, warm candlelight, surprising pops of color on a dark background.

### Aesthetic Direction
Dark theme — deep navy/indigo backgrounds (#0d0d1a), warm cream/gold text. The existing palette is already right: Cinzel for fantasy headings, Crimson Text for body. Accents should feel gem-like (jewel tones), not neon. Reference games: Pokémon TCG Online (organized, chunky, fun), Runeterra (rich, polished), Gwent (physical table gravity). Anti-reference: generic SaaS dark dashboards, glowing cyan/purple gradients.

### Design Principles
1. **Clarity before cleverness** — kids need to understand it at a glance. Labels must be unambiguous.
2. **Dense but not crowded** — 40+ releases must fit without scrolling forever. Use compact rows, not sprawling chips.
3. **Emoji does the heavy lifting** — each release's emoji is distinctive; lean on it for visual identity instead of colored borders.
4. **The game is the hero** — setup screens are friction. Minimize visual weight so players get to the board fast.
5. **Warm, not cold** — prefer rounded corners, cozy spacing, and gold/amber accents over sharp/clinical layouts.
